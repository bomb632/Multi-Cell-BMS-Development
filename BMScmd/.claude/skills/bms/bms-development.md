# BMS (电池管理系统) 开发技能指南

## BMS 基础概念

### 什么是 BMS？

BMS (Battery Management System) 是电池管理系统的缩写，用于监控和管理电池组的状态，确保电池安全、可靠、高效运行。

### BMS 核心功能

| 功能 | 说明 |
|------|------|
| **电压监测** | 监测各串电池电压，防止过压/欠压 |
| **电流监测** | 监测充放电电流，实现过流保护 |
| **温度监测** | 监测电池温度，防止过热/过冷 |
| **SOC估算** | 估算电池剩余电量 |
| **均衡管理** | 平衡各串电池容量，延长电池寿命 |
| **保护控制** | 异常时切断MOSFET，保护电池 |
| **通信接口** | 与外部系统交换数据 |

## BMS 软件架构

### 推荐架构：时间片轮询 + 状态机

```c
// 主循环结构
while(1) {
    // 1. 更新时间片标志
    Update_Time_Flags();

    // 2. 数据采集层（不同时间片）
    if(flag_10ms)   ADC_Sample();           // ADC采集
    if(flag_100ms)  Voltage_Collect();      // 电压采集
    if(flag_200ms)  Current_Temp_Collect(); // 电流/温度采集
    if(flag_500ms)  Config_Read();          // 配置读取

    // 3. 数据处理层
    if(flag_200ms)  SOC_Calculate();        // SOC计算
    if(flag_200ms)  Balance_Control();      // 均衡控制

    // 4. 保护控制层
    if(flag_100ms)  Protection_Check();     // 保护检测
    if(flag_100ms)  MOS_Control();          // MOS控制

    // 5. 通信层
    Communication_Process();                // 通信处理

    // 6. 清除标志
    Clear_Time_Flags();
}
```

## SOC 估算算法

### 常用 SOC 估算方法

| 方法 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| **开路电压法(OCV)** | 静置电压对应SOC | 简单、准确 | 需要静置时间 | 初始化、长期静置 |
| **库仑计法(CC)** | 积分电流计算充放电量 | 动态准确 | 有累积误差 | 运行中SOC估算 |
| **卡尔曼滤波** | 融合多种方法 | 高精度、自适应 | 复杂、计算量大 | 高端BMS |
| **查表法** | 电压-SOC对照表 | 简单快速 | 精度较低 | 低成本方案 |

### 推荐方案：OCV + CC 组合

```c
// SOC计算流程
void SOC_Calculate(void) {
    // 1. 初始SOC用OCV法确定
    if(系统初始化 || 长期静置) {
        SOC = OVSOC_Get(Voltage);
    }

    // 2. 运行中用库仑计积分
    else {
        SOC += (Current * dt) / Capacity;
    }

    // 3. 限制范围0-100%
    SOC = Limit(SOC, 0, 100);

    // 4. 定期用OCV校准
    if(静置时间 > 阈值) {
        SOC = OVSOC_Get(Voltage);
    }
}
```

## 电池均衡策略

### 主动均衡 vs 被动均衡

| 类型 | 原理 | 优点 | 缺点 | 成本 |
|------|------|------|------|------|
| **被动均衡** | 电阻放电高电压串 | 简单、可靠 | 能量损耗、发热 | 低 |
| **主动均衡** | 电容/电感转移能量 | 效率高 | 复杂、成本高 | 高 |

### 被动均衡控制策略

```c
// 简化均衡控制逻辑
void Balance_Control(void) {
    // 1. 找出最高电压的串
    max_cell = Find_Max_Voltage_Cell();
    voltage_diff = max_cell.voltage - avg_voltage;

    // 2. 判断是否需要均衡
    if(voltage_diff > BALANCE_THRESHOLD) {
        // 3. 检查均衡条件
        if(允许均衡 && 温度正常 && 电流<阈值) {
            // 4. 开启均衡
            Balance_Enable(max_cell.id);
        }
    } else {
        // 5. 关闭均衡
        Balance_Disable_All();
    }
}
```

## 保护参数配置

### 典型保护阈值 (以三元锂电池为例)

| 参数 | 充电 | 放电 | 延迟 | 恢复 |
|------|------|------|------|------|
| **过压(OV)** | 4.2-4.25V/串 | - | 1-2s | 4.1-4.15V/串 |
| **欠压(UV)** | - | 2.7-3.0V/串 | 1-2s | 3.0-3.2V/串 |
| **过流(OCP)** | 根据电池规格 | 根据电池规格 | 瞬时 | 电流正常 |
| **短路(SCD)** | >200A | >200A | 200-500us | 清除故障 |
| **过温(OTP)** | >60℃ | >60℃ | 1-5s | <45℃ |
| **欠温(UTP)** | <0℃ | < -20℃ | 1-5s | >5℃ |

### 保护实现流程

```c
void Protection_Check(void) {
    // 1. 读取AFE状态寄存器
    status = AFE_Get_Status();

    // 2. 检查硬件保护
    if(status & OV_FLAG)   Handle_Over_Voltage();
    if(status & UV_FLAG)   Handle_Under_Voltage();
    if(status & OCD_FLAG)  Handle_Over_Current();
    if(status & SCD_FLAG)  Handle_Short_Circuit();

    // 3. 软件保护检查
    Software_Protection_Check();

    // 4. MOS控制
    MOS_Control_By_Protection_Status();
}
```

### 常见问题排查

| 问题 | 可能原因 | 排查方法 |
|------|----------|----------|
| 电压读数为0 | I2C通信失败 | 检查硬件连接、上拉电阻 |
| SOC不准确 | 库仑计漂移 | 重新OCV校准 |
| 均衡不工作 | 电压差不够 | 检查阈值设置 |
| MOS无法控制 | 控制逻辑错误 | 检查状态机流程 |
