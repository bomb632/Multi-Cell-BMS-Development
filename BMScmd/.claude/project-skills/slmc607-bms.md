# SLMC607 BMS 项目技能文档

## 项目概述

**产品型号**: SLMC607 电池管理系统 (BMS)
**MCU**: STM32F10x 系列
**AFE芯片**: TI BQ76930/BQ76940 (3-10/15串电池模拟前端)
**通信方式**: RS485 (UART2, 115200波特率)
**开发环境**: Keil uVision 4/5

## 软件架构：时间片轮询

主循环采用**非阻塞时间片轮询架构**，各模块按固定时间片执行：

```c
while(1) {
    Systim_Time_Run();      // 更新时间片标志
    Sys_Rece_Data();        // RS485接收处理
    Sys_Send_Data();        // RS485发送处理
    Get_Base_Data();        // 基础数据采集
    Mix_Function_Pro();     // 混合功能处理
    Clear_flag();           // 清除时间片标志
}
```

### 时间片分配

| 时间片 | 周期 | 功能 |
|--------|------|------|
| 1ms | TIM1中断 | 系统滴答，时间片计数 |
| 100ms | 主循环 | MOSFET控制、通信操作 |
| 200ms | 主循环 | 电压/电流采集、均衡状态机 |
| 500ms | 主循环 | 温度采集、配置读取、唤醒处理 |

## BQ769xx AFE芯片驱动 (bq769xx.c)

### I2C通信

- **I2C地址**: 0x08 (7位地址)
- **CRC校验**: CRC8，多项式 0x07
- **通信方式**: STM32通过I2C与BQ769xx通信

### 关键寄存器

| 寄存器 | 地址 | 功能 |
|--------|------|------|
| SYS_STAT | 0x00 | 系统状态（告警标志） |
| CELLBAL1-3 | 0x01-0x03 | 均衡控制（Cell 1-15） |
| SYS_CTRL1 | 0x04 | ADC使能、温度选择 |
| SYS_CTRL2 | 0x05 | MOS控制、库仑计 |
| PROTECT1-3 | 0x06-0x08 | 保护配置 |
| OV_TRIP | 0x09 | 过压阈值 |
| UV_TRIP | 0x0A | 欠压阈值 |
| VC1_HI-VC15_LO | 0x0C+ | 电池电压值 |

## RS485通信协议详解

### 协议文件
`通信协议/SLMC60X_RS485通信协议 v1.2.xlsx`

### 通信参数
- **接口**: RS485
- **波特率**: 115200
- **数据位**: 8
- **停止位**: 1
- **校验**: 无

### 帧格式定义

#### 主机请求格式
```
┌──────┬──────┬──────┬──────┬──────┬────────┐
│ 起始符│设备ID│命令码│数据长│  数据 │  CRC   │
├──────┼──────┼──────┼──────┼──────┼────────┤
│ 0xA8 │ 0x11 │ Fun  │ Len  │ Data │ Sum+1  │
└──────┴──────┴──────┴──────┴──────┴────────┘
```

#### BMS响应格式
```
┌──────┬──────┬──────┬──────┬──────┬────────┐
│ 起始符│设备ID│命令码│数据长│  数据 │  CRC   │
├──────┼──────┼──────┼──────┼──────┼────────┤
│ 0xA8 │ 0x11 │ Fun  │ Len  │ Data │ Sum+1  │
└──────┴──────┴──────┴──────┴──────┴────────┘
```

### 命令字列表

| 命令码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | 读取参数 | 读取BQ769xx增益和偏置值 |
| 0x02 | 读取数据 | 读取电压、电流、温度、SOC |
| 0x03 | 读取配置 | 读取BQ769xx寄存器状态 |
| 0x04 | 设置指令 | 控制MOS、清除告警、进入休眠 |

### 命令详解

#### 0x01 - 读取参数
**请求**: `A8 11 01 01 00 45`
**响应**: `A8 11 01 03 [增益高位 增益低位 偏置] CRC`

#### 0x02 - 读取电压电流温度 (最重要)
**请求**: `A8 11 02 01 00 44`
**响应**: `A8 11 02 28 [42字节数据] CRC`

返回数据结构:
| 字节 | 数据 | 单位 | 类型 |
|------|------|------|------|
| D5-D6 | VC1-VC15电压 | 0.001V | u16大端 |
| D35-D36 | 总电压BAT | 0.001V | u16大端 |
| D37-D38 | 温度TS1 | 0.1℃ | u16大端 |
| D39-D40 | 温度TS2 | 0.1℃ | u16大端 |
| D41-D42 | 温度TS3 | 0.1℃ | u16大端 |
| D43-D44 | 电流CC | 0.01A | i16大端(有符号) |
| D45-D46 | SOC | 0.1% | u16大端 |
| D47-D50 | 均衡状态 | - | u32大端 |

#### 0x03 - 读取配置
**请求**: `A8 11 03 01 00 43`
**响应**: `A8 11 03 0B [12字节寄存器数据] CRC`

返回BQ769xx寄存器: SYS_STAT, CELLBAL1-3, SYS_CTRL1-2, PROTECT1-3, OV_TRIP, UV_TRIP, CC_CFG

#### 0x04 - 设置指令
**请求**: `A8 11 04 01 [数据] CRC`
**响应**: 无

设置指令:
| 数据 | 指令 |
|------|------|
| 0x01 | DSG_ON - 闭合放电MOS |
| 0x02 | DSG_OFF - 断开放电MOS |
| 0x03 | CHG_ON - 闭合充电MOS |
| 0x04 | CHG_OFF - 断开充电MOS |
| 0x05 | CLEAR_ALERT - 清除告警 |
| 0x06 | ENTER_SHIP - 进入休眠 |

### CRC计算
```c
u8 Crc_CheckSum(u8 *buff, u16 leng) {
    u8 ret = 0;
    for(u8 i = 0; i < leng; i++) {
        ret += buff[i];
    }
    ret = ~ret + 1;  // 取反加1
    return ret;
}
```

## 配置参数详解 (ConfigPara.c)

### 参数结构体

```c
typedef struct BMSConfig {
    sSystem_Type Type;          // 硬件规格参数
    sSystem_Balan Balan;        // 均衡策略参数
    sSystem_BQ76Para BQ76Para;  // BQ769xx保护参数
    u8 DataCRC;                 // CRC校验码
} sBMSConfig;
```

### 1. 硬件规格参数 (sSystem_Type)

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| CapaRate | u64 | 额定容量 (mAh) | 2000 (2Ah) |
| VoltSpec | u8 | 额定电压 | 18V (5串) |
| CellNum_Ser | u8 | 串联数 | 5串 |
| CellNum_Par | u8 | 并联数 | 1并 |
| TempNum | u8 | 温度传感器数量 | 1个 |
| ShuntSpec | u16 | 分流电阻规格 (mΩ) | 5000 (5mΩ) |
| OCVDaleyTime | u16 | OCV延迟时间 (秒) | 600 (10分钟) |

### 2. 均衡策略参数 (sSystem_Balan)

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| balanc_start_volt | u16 | 均衡启动电压 (mV) | 3000 (3.0V) |
| balanc_diffe_volt | u16 | 均衡压差阈值 (mV) | 100 (0.1V) |
| balanc_number_max | u16 | 最多同时均衡串数 | 3串 |
| balanc_oneall_time | u16 | 单次均衡时间 (200ms计数) | 900 (180秒) |

**均衡策略说明**:
- 当最高单串电压 > `balanc_start_volt`
- 且最高与最低电压差 > `balanc_diffe_volt`
- 且温度正常、电流小于阈值
- 则开启均衡，每次均衡持续 `balanc_oneall_time * 200ms`

### 3. BQ769xx保护参数 (sSystem_BQ76Para)

#### 短路保护 (SCD)

| 寄存器值 | 延迟时间 |
|----------|----------|
| 0x00 | 70us |
| 0x01 | 100us |
| 0x02 | 200us |
| 0x03 | 300us |

**SCD_Thresh 阈值** (RSNS=1高量程):
| 寄存器值 | 分流电压 | 对应电流(5mΩ分流器) |
|----------|----------|---------------------|
| 0x07 | 200mV | 40A |

#### 过流保护 (OCD)

| 寄存器值 | 延迟时间 |
|----------|----------|
| 0x00 | 8ms |
| 0x07 | 1280ms |

**OCD_Thresh 阈值** (RSNS=1高量程):
| 寄存器值 | 分流电压 | 对应电流(5mΩ分流器) |
|----------|----------|---------------------|
| 0x0F | 100mV | 20A |

#### 过压/欠压保护 (OV/UV)

| 参数 | 寄存器值范围 | 延迟时间 |
|------|-------------|----------|
| UV_Delay | 0x00-0x03 | 1s/4s/8s/16s |
| OV_Delay | 0x00-0x03 | 1s/4s/8s/16s |
| UV_Thresh | 1580-3100 mV | 欠压阈值 |
| OV_Thresh | 3150-4700 mV | 过压阈值 |

**默认配置值**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| UV_Thresh | 2500mV | 2.5V欠压保护 |
| OV_Thresh | 4200mV | 4.2V过压保护 |
| UV_Delay | 0x03 | 约2秒延迟 |
| OV_Delay | 0x03 | 约2秒延迟 |

2. **重新初始化Flash**: 取消注释 `main.c` 中的 `FLASH_Update_Data()` 并运行一次
3. **上位机修改**: 使用 `SLMC60X_Tool_uart v1.5.exe` 在线修改

## 状态机详解

### 第一层状态机：系统模式切换 (TaskFun.c)

**执行周期**: 200ms
**函数**: `Sys_Mode_Charge()`

```
                    ┌─────────────────┐
                    │     SLEEP       │ 休眠模式
                    │  (电流>20mA唤醒) │
                    └────────┬─────────┘
                             │
            电流绝对值>20mA  ▼
                    ┌─────────────────┐
         ┌──────────│    STANDBY      │ 待机模式
         │          │  (-20mA~20mA)   │
         │          └────────┬─────────┘
         │                   │
    电流≤-20mA         电流≥20mA     静置2小时
         │                   │             │
         ▼                   ▼             ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│   DISCHARGE     │ │    CHARGE       │ │     SLEEP       │
│   放电模式       │ │   充电模式       │ │   休眠模式       │
│  (电流≤-20mA)   │ │  (电流≥20mA)    │ │                 │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

**模式切换条件**:
- **SLEEP → STANDBY**: 检测到充电器或负载 (电流绝对值>20mA)
- **STANDBY → DISCHARGE**: 放电电流 ≥20mA
- **STANDBY → CHARGE**: 充电电流 ≥20mA
- **STANDBY → SLEEP**: 静置2小时后进入休眠
- **DISCHARGE/CHARGE → STANDBY**: 电流回到 -20mA~20mA

### 第二层状态机：BQ769xx通信操作 (bq769xx.c)

**执行周期**: 100ms
**函数**: `BQ769xx_Oper_Comm()`

处理MOSFET开关控制、告警清除、关机流程等操作。

### 第三层状态机：均衡控制 (bq769xx.c)

**执行周期**: 200ms
**函数**: `Balan_Pack_Check()`

```
INIT → WAIT → CHK → SELECT → MAP → SET → BALA_TIM
  ↑                                                │
  └────────────────────────────────────────────────┘
```

| 状态 | 说明 |
|------|------|
| INIT | 初始化均衡状态 |
| WAIT | 等待均衡条件满足 |
| CHK | 检查电压差是否需要均衡 |
| SELECT | 选择需要均衡的电池串 |
| MAP | 映射到BQ769xx寄存器位 |
| SET | 写入均衡寄存器 |
| BALA_TIM | 均衡计时中 |

## 故障诊断指南

### 1. 告警标志诊断 (SYS_STAT寄存器)

**读取方式**: 发送 0x03 命令读取配置寄存器

| 告警标志 | 位 | 说明 | 处理方法 |
|----------|----|----|----------|
| OCD | Bit0 | 过流告警 | 检查负载是否短路，排除后发送 CLEAR_ALERT |
| SCD | Bit1 | 短路告警 | 立即断开负载，检查硬件连接 |
| OV | Bit2 | 过压告警 | 检查充电器电压是否过高 |
| UV | Bit3 | 欠压告警 | 检查电池是否过放，需要充电 |
| OVRD_ALERT | Bit4 | 覆盖告警 | I2C通信异常 |
| DEVICE_XREADY | Bit5 | 设备就绪 | ADC转换完成 |
| WAKE | Bit6 | 唤醒标志 | 从SHIP模式唤醒 |
| CC_READY | Bit7 | 库仑计就绪 | 库仑计数据可读 |

### 2. 常见故障排查

#### 故障1: 电压读数为0

**可能原因**:
- I2C通信失败
- BQ769xx未唤醒
- 电池未连接

**排查步骤**:
1. 检查I2C上拉电阻 (通常2.2kΩ-10kΩ)
2. 用示波器观察I2C波形 (SDA/SCL)
3. 检查BQ769xx WAKE引脚是否拉高1秒
4. 测量BQ769xx供电电压 (VS引脚)

#### 故障2: SOC不准确

**可能原因**:
- 库仑计漂移累积
- 容量参数设置错误
- OCV未校准

**处理方法**:
1. 静置电池10分钟以上
2. 让系统自动用OCV校准SOC
3. 检查 `ConfigPara.c` 中容量设置是否正确
4. 重新初始化SOC: 断电后重新上电

#### 故障3: 均衡不工作

**可能原因**:
- 电压差未达到阈值
- 电池电压过低
- 温度异常

**排查步骤**:
1. 检查各串电压差是否 >100mV
2. 检查最低电压是否 >3000mV
3. 检查温度是否在正常范围
4. 查看均衡寄存器值是否被正确写入

#### 故障4: MOSFET无法控制

**可能原因**:
- 告警状态存在
- 控制时序错误
- 硬件损坏

**排查步骤**:
1. 读取SYS_STAT寄存器，确认无告警
2. 发送CLEAR_ALERT命令清除告警
3. 用上位机发送DSG_ON/CHG_ON测试
4. 检查MOSFET栅极驱动电压

#### 故障5: RS485通信失败

**可能原因**:
- 波特率不匹配
- 接线错误
- 终端电阻缺失

**排查步骤**:
1. 确认波特率115200
2. 检查A/B线是否接反
3. 添加120Ω终端电阻
4. 用示波器观察差分信号

## 常见问题

**Q: 如何修改电池串数？**
A: 修改 `ConfigPara.c` 中的 `gBMSConfig.Type.CellNum_Ser` 参数

**Q: 如何调整保护阈值？**
A: 修改 `ConfigPara.c` 中的 `BQ76Para` 结构体相关阈值

**Q: 如何启用/禁用均衡功能？**
A: 修改 `ConfigPara.c` 中的 `balanc_start_volt` 参数来调整均衡启动条件

**Q: 首次使用如何初始化Flash？**
A: 在 `main.c` 中取消注释 `FLASH_Update_Data()` 并编译运行一次

**Q: 如何修改分流电阻值？**
A: 修改 `ConfigPara.c` 中的 `gBMSConfig.Type.ShuntSpec` 参数

**Q: 为什么SOC跳变？**
A: 可能是OCV校准触发，静置10分钟后会自动校准
