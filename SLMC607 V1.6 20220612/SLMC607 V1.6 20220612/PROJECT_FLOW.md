## 三、时间片架构

### 3.1 时间片生成链

```
1ms中断 (TIM1)
    │
    ▼ 累计10次
10ms (Tim10ms_count >= 10)
    │
    ▼ 累计10次
100ms (Tim100ms_count >= 10)
    │
    ├─────────────────────┬─────────────────────┐
    ▼                     ▼                     ▼
200ms                  500ms                   1s
(Tim200ms_count >= 2)  (Tim500ms_count >= 5)  (Tim1s_count >= 2)
    │                     │                     │
    │                     │                     ▼
    │                     │                  10s
    │                     │                  (Tim10s_count >= 10)
    │                     │                     │
    │                     │                     ▼
    │                     │                  1min
    │                     │                  (Tim1min_count >= 6)
    │                     │
    └─────────────────────┴─────────────────────┐
                                                  ▼
                                          主循环轮询执行
```

### 3.2 时间片用途分配表

| 时间片 | 周期 | 功能模块 |
|-------|------|---------|
| 10ms  | 10ms | (备用) |
| 100ms | 100ms | 继电器/MOSFET控制、通信操作状态机、LED更新 |
| 200ms | 200ms | 电压电流采集、模式判断、均衡状态机、SOC计算 |
| 500ms | 500ms | 温度采集、配置读取、BQ769xx唤醒处理 |
| 1s    | 1s   | (扩展用) |
| 10s   | 10s  | (扩展用) |
| 1min  | 1min | (扩展用) |

## 四、三层状态机架构

### 4.1 第一层状态机：系统模式切换

```
                    SLEEP (休眠模式)
                 电流绝对值 > 20mA 时唤醒
                         │
                         ▼
    ┌──────────────────────────────────────────┐
    │            STANDBY (待机模式)             │
    │          电流在 -20mA ~ 20mA 之间         │
    │                                          │
    │  条件1: 静置2小时 → SLEEP                │
    │  条件2: 电流 ≤ -20mA → DISCHARGE         │
    │  条件3: 电流 ≥ 20mA → CHARGE             │
    └──────────────────────────────────────────┘
                │                   │
      电流 ≤ -20mA              电流 ≥ 20mA
                │                   │
                ▼                   ▼
    ┌──────────────────┐  ┌──────────────────┐
    │  DISCHARGE       │  │     CHARGE       │
    │  (放电模式)       │  │   (充电模式)     │
    └──────────────────┘  └──────────────────┘
        │                   │
        └─── -20mA < 电流 < 20mA ───┘
                    │
                    ▼
               STANDBY
```

**状态转换条件：**
| 当前状态 | 目标状态 | 触发条件 |
|---------|---------|---------|
| SLEEP | STANDBY | 电流绝对值 > 20mA |
| STANDBY | SLEEP | 静置2小时 (200ms × 36000) |
| STANDBY | DISCHARGE | 电流 ≤ -20mA |
| STANDBY | CHARGE | 电流 ≥ 20mA |
| DISCHARGE/CHARGE | STANDBY | -20mA < 电流 < 20mA |

### 4.2 第二层状态机：均衡控制

```
┌─────────────────────────────────────────────────────────────────┐
│                    均衡控制状态机 (200ms时间片)                    │
└─────────────────────────────────────────────────────────────────┘

    ┌─────────┐
    │  INIT   │  初始化状态：关闭所有均衡
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │  WAIT   │  等待状态：延时2秒 (200ms × 10)
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │   CHK   │  检查状态：判断是否满足均衡条件
    └────┬────┘
         │
         │ 不满足条件 (不在待机 OR 压差不足 OR 电压过低)
         │
         └──────→ INIT
         │
         │ 满足条件
         ▼
    ┌─────────┐
    │ SELECT  │  选择状态：冒泡排序选择电压最高的N串
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │   MAP   │  映射状态：逻辑位 → 物理寄存器位
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │   SET   │  设置状态：写入均衡寄存器
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │BALA_TIM │  均衡计时：均衡180秒 (200ms × 900)
    └────┬────┘
         │
         │ 180秒后
         │
         └──────→ INIT
```

**均衡启动条件：**
1. 系统模式为 STANDBY (待机模式)
2. 压差 ≥ 配置阈值 (`balanc_diffe_volt`)
3. 最低电压 ≥ 启动电压 (`balanc_start_volt`)

## 七、均衡算法流程

```
┌──────────────────────────────────────────────────────────────────┐
│                      冒泡排序均衡算法                             │
└──────────────────────────────────────────────────────────────────┘

                              电池电压数组
                    [V1, V2, V3, V4, V5]
                              │
                              ▼
    ┌────────────────────────────────────────────────────┐
    │ 冒泡排序 (降序)                                    │
    │ 从高到低排序电池电压                               │
    │ 例如: [4200, 4180, 4160, 4150, 4140] mV           │
    └────────────────────────────────────────────────────┘
                              │
                              ▼
    ┌────────────────────────────────────────────────────┐
    │ 选择前N串最高电压进行均衡                          │
    │ 例如: N=2, 选择4200mV和4180mV的电池               │
    └────────────────────────────────────────────────────┘
                              │
                              ▼
    ┌────────────────────────────────────────────────────┐
    │ cell_balan_locatget(): 逻辑位 → 物理寄存器位      │
    │ 根据Cells_Map将逻辑电池编号映射到BQ769xx通道      │
    └────────────────────────────────────────────────────┘
                              │
                              ▼
    ┌────────────────────────────────────────────────────┐
    │ balance_write_regs(): 写入均衡寄存器              │
    │ CELLBAL1: Bit0-4 控制Cell1-5                      │
    │ CELLBAL2: Bit0-4 控制Cell6-10                     │
    │ CELLBAL3: Bit0-4 控制Cell11-15                    │
    └────────────────────────────────────────────────────┘
                              │
                              ▼
    ┌────────────────────────────────────────────────────┐
    │ 均衡180秒 (200ms × 900)                           │
    │ 被动均衡：通过内部电阻放电                        │
    └────────────────────────────────────────────────────┘
                              │
                              ▼
                         关闭均衡
                        返回INIT状态
```

## 九、保护机制

### 9.1 硬件保护 (BQ769xx)

| 保护类型 | 触发条件 | 动作 |
|---------|---------|------|
| SCD (短路) | 电流 > SCD_Thresh，持续 > SCD_Delay | 立即关断MOSFET |
| OCD (过流) | 电流 > OCD_Thresh，持续 > OCD_Delay | 延迟后关断MOSFET |
| OV (过压) | 单串电压 > OV_Thresh，持续 > OV_Delay | 延迟后关断充电MOSFET |
| UV (欠压) | 单串电压 < UV_Thresh，持续 > UV_Delay | 延迟后关断放电MOSFET |

### 9.2 软件告警

| 告警类型 | 说明 |
|---------|------|
| OVP | 过压告警 |
| UVP | 欠压告警 |
| OCP | 过流告警 |
| UCP | 欠流告警 |
| OTP | 过温告警 |
| UTP | 欠温告警 |
| USOC | SOC过低告警 |

## 附录：关键数据结构

### sBMSData (BMS数据总结构体)

```c
typedef struct BMSData {
    sBattPar      BattPar;      // 电池参数(电压/电流/温度/SOC)
    sChargePar    ChargePar;    // 充电参数
    sStatePar     StatePar;     // 状态参数(MOSFET状态)
    sbalaPar      BalaPar;      // 均衡参数
    sPackCap      PackCap;      // 容量参数
    sAlarmPar     AlarmPar;     // 告警参数
    sErrorPar     ErrorPar;     // 错误参数
    sSys_Mod      Sys_Mod;      // 系统模式
    sSoftw_Ver    Softw_Ver;    // 软件版本
    sGpio_State   Gpio_State;   // GPIO状态
} sBMSData;
```
