# SLMC607 BMS 项目概览

## 项目基本信息
| 属性 | 值 |
|------|------|
| 产品名称 | SLMC607 电池管理系统 |
| 版本 | V1.6 |
| 日期 | 2022-06-12 |
| 公司 | 上海芯联集成电路有限公司 |
| MCU | STM32F10x (ARM Cortex-M3) |
| AFE芯片 | BQ76920/BQ76940 (TI) |
| 电池串数 | 5-15串可配置 |
| 通信接口 | I2C + UART/RS485 |

## 软件架构特点
- **主架构**: 时间片轮询 + 三层状态机
- **设计原则**: 非阻塞、状态机驱动、工业级可靠
- **参数保存**: Flash存储 + CRC校验

## 关键文件说明
```
Source/App/
├── main.c          # 主循环入口
├── TaskFun.c       # 系统模式状态机
├── bq769xx.c       # AFE驱动 + 均衡状态机
├── ConfigPara.c    # 参数配置中心
└── DataBase.h      # 全局数据结构
```
