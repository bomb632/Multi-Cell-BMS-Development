## 关键概念速记

### 架构模式
- **时间片轮询** + **三层状态机**
- 100ms/200ms/500ms 时间分片
- 非阻塞设计

### 三层状态机
1. **系统模式**: SLEEP/STANDBY/CHARGE/DISCHARGE
2. **均衡控制**: INIT→WAIT→CHK→SELECT→MAP→SET→BALA_TIM
3. **通信操作**: MOS开关/告警清除/关机

### 核心文件
| 文件 | 作用 |
|------|------|
| main.c | 主循环入口 |
| TaskFun.c | 系统状态机 |
| bq769xx.c | AFE驱动+均衡 |
| ConfigPara.c | 参数配置 |
